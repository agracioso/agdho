# AGDHO · Alexandre Gracioso

Site one-page de consultoria para instituições de ensino superior e organizações da economia do conhecimento.

- Publicado via GitHub Pages: https://agracioso.github.io/agdho/
- HTML/CSS estáticos, sem dependências de build. Estilos no Design System AGDHO v2 (`assets/tokens.css`, `assets/bundle.css`, `assets/site.css`).
- Para editar textos, altere `index.html`. Fotos em `assets/img/`.
